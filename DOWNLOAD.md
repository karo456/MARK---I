# Download

Prefer a ready-to-run copy instead of cloning? Grab the full project (zipped) from MediaFire:

**[Download MARK 1 (.zip)](https://www.mediafire.com/file/u53mh2h0vzpadap/jarvis-git.zip/file)**

## Setup
1. Extract the zip.
2. Install the requirements: `pip install -r requirements.txt`
3. Run `python ui.py` (or double-click `run.bat`).
4. On first launch you'll be asked for your Gemini API key (free at https://aistudio.google.com/apikey) — see `README.md` for full details and all the features.

> Note: the zip is a personal build and may include local files that are normally excluded from the repo by `.gitignore` (e.g. a filled-in `.env`, saved memory, logs). Review it before sharing further, and remove anything you don't want public.
